# LC-motivated sleep physiology in human iEEG

## Audit status: corrected cohort results pending

The numerical results committed on this branch were generated by superseded estimators. They are
retained only as historical provenance and must not be cited as current findings. In particular,
the former claims that 3A was negative, 3B was weak/present, or 3D was present are withdrawn until
the raw data are rebuilt and quality-controlled with the current versioned pipeline.

Current production outputs must carry:

```text
analysis_version = 2026-07-corrected-v5
cache_schema_version = 2026-07-per-contact-power-pchip-night-threshold-v5
```

No committed cohort JSON currently satisfies those requirements. See the proof-backed
[issue register](docs/ISSUE_REGISTER_2026-07.md) and
[audit corrections](docs/AUDIT_CORRECTIONS_2026-07.md).

## What this study can test

The branch examines three kinds of NREM physiology:

| Test | Measurement | Defensible interpretation |
|---|---|---|
| 3A | Infraslow structure in 10–15 Hz sigma power, plus sigma–cardiac cross-correlation | An **LC-motivated candidate signature**, adapted from Lecci; not an LC measurement |
| 3B | Timing of RR minima/heart-rate bursts after cortical slow-oscillation down-states | A CNS–autonomic timing measure adapted from Naji; not an LC-specific proxy |
| 3D | Slow-oscillation phase at one maximal 12–16 Hz spindle per SO epoch | Generic SO–spindle nesting and a signal-quality/physiology check; not an LC proxy |

Only Osorio-Forero directly measured and manipulated LC/noradrenergic mechanisms, and that work was
in mice. Lecci measured human sigma and heart rate observationally and proposed possible arousal
generators. Naji, Staresina, and Helfrich did not validate an LC measure. Consequently this
repository cannot prove human LC specificity without an independent LC/NE-sensitive measurement
or intervention.

SWA means **slow-wave activity**: broadband EEG/iEEG power at approximately **0.5–4 Hz**. It tends
to rise in deeper NREM. SWA is not a discrete slow-oscillation event and is not an LC measurement.

## What the audit fixed

- 3A power is computed per contact before averaging, so phase/polarity cancellation cannot erase
  power.
- Per-contact power is normalized once over the full night, not independently in each 10-minute
  chunk.
- Streamed cache filtering uses 30 s of context on both sides of every 10-minute chunk and writes
  only the core, preventing internal filter/Hilbert edge artifacts.
- Original missing-sample masks are retained and dilated by 5 s; filled values are numerical filter
  scaffolding only and cannot contribute to power bins, epochs, events, or R peaks.
- Sigma aggregation requires at least three contacts with ≥80% per-contact coverage and at least
  80% of that fixed selected set in each reported bin; the contact coverage/count provenance is
  stored.
- Human SWA is 0.5–4 Hz; fixed 10–15 Hz sigma is primary. The SWA negative control is measured in
  the same sigma-defined frequency window, not at an independently selected SWA peak; this
  sigma-selected comparison is descriptive unless selection is repeated inside a joint null.
- The second Morlet analysis uses 0.001–0.12 Hz, four cycles, mandatory four-second smoothing, and
  common bout support across frequency.
- Gaussian peak fitting may return “no peak” and records fit quality, spectral width, and the
  paper-defined peak-window value.
- Constant/zero-variance power and zero-autospectrum coherence are treated as unavailable endpoints,
  not as measured null results.
- RR interpolation is shape-preserving and explicitly masks both endpoints of gaps longer than
  5 s, so a 5.1 s beat gap cannot be reopened downstream as a nominal 5 s NaN run. The Naji event
  curve and its stage denominator use one consistent RR-to-HR definition.
- RESPect excludes BIDS channels marked bad, requires good iEEG/ECG/EMG/EOG, and both stage proxies
  fail closed when a stable high-delta or N2-like/N3-like partition is not supported. Passing that
  density-fit gate does not prove two physiological states.
- RESPect robust feature centers/scales are fit only on jointly finite clean epochs, so discarded
  data cannot move the thresholds applied to retained epochs.
- Staging spectra are unavailable for an artifact-tainted contact-epoch. Epoch features use one
  fixed full-night contact set, within-contact SWA normalization, and at least 80% support from that
  exact set; changing contact gain/availability cannot manufacture a stage-proxy mode.
- 3B thresholds clean SO candidates within stage, averages Naji electrode/channel peak times, and
  uses only cache coverage-qualified contacts, with at least two contacts still contributing 30
  complete in-stage RR windows. One shared within-stage circular shift preserves cross-channel
  dependence, but is diagnostic only because it does not preserve local nonstationary HR
  trends/event clustering; 3B event-locking inference is disabled pending a valid local null.
- 3D uses fixed 0.16–1.25 Hz SO and 12–16 Hz spindle bands, whole-NREM channel-night thresholds,
  padded IED/artifact rejection, and at most one maximum-amplitude spindle per SO.
- Per-contact Rayleigh values and pooled participant vectors in 3D are descriptive only. The former
  participant-rotation test is disabled because selecting the nearest spindle inside a finite
  SO-centered window creates a shared phase direction even for independent event trains.
- A pooled 3D participant must have at least three included contacts and 200 paired events from
  those contacts, with at least 1,200 s and 80% valid pooled NREM per included contact.
- Caches store a digest of the cache-producing source and environment specification, not only a
  broad Git/tree label.
  Cache files also embed and verify participant identity. Results pin the exact cache manifest and
  NPZ hashes; terminal manifests pin every output JSON/NPZ byte hash; reuse verifies the prior
  terminal hashes before touching a manifest. Non-standard NaN/Infinity JSON is rejected. Results
  record explicit endpoint availability and mark a subject partial with a reason when a required
  endpoint is not estimable.
- Every runner creates an `in_progress` manifest before subject work. Caught subject failures are
  finalized explicitly; an unexpected process interruption deliberately leaves the manifest
  `in_progress`, which summaries reject. Missing/`None` results are classified rather than
  disappearing; failed runs are rejected. A partial subject contributes only to endpoints that are
  actually available, with endpoint-specific denominators, reasons, and minimum sample-size gates.
- The HUP interval selector now preserves failed sparse probes in physical time, scans the complete
  recording, includes the final legal window, and labels its result as a sparse-probe high-delta
  candidate—not a densely measured night or verified sleep onset.
- Withdrawn 3A/3B/3D command-line generators, follow-ups, figures, the combined pipeline, and its
  summarizer are hard-stopped.

Synthetic regression tests demonstrate many of the corresponding failure modes and fixes; the issue
register states additional acceptance checks. Neither substitutes for a corrected raw-data rerun.

## Important unresolved limitations

The implementation defects above are fixed in the working tree. The following scientific and
validation limitations remain **open** and cannot be repaired by relabeling an output:

- HUP N2-like/N3-like labels are unvalidated slow-wave/GMM proxies, not expert AASM/R&K stages.
  RESPect uses an unvalidated EMG/EOG/iEEG rule set, also not expert scoring. A stable two-Gaussian
  fit can partition a single skewed unimodal distribution, so its “high” class is not evidence of a
  latent sleep state.
- HUP contacts are selected by a contact-number heuristic. Coordinates, gray-matter/region labels,
  bad contacts, seizure-onset zones, and clinical review are still required.
- The 1 Hz Hilbert/Butterworth sigma series is an approximation to Lecci’s 0.1 s FieldTrip Morlet
  construction and must be benchmarked against a validated reference implementation.
- The chosen HUP interval is a high-delta candidate interval, not known lights-off/sleep-onset.
- Missing-data exclusion is now explicit in code, but it and the NeuroKit R peaks, SOs, spindles,
  artifacts, and stage labels still need blinded raw-data validation.
- Current ECG preprocessing/detection uses NeuroKit's default method, not Naji's Pan–Tompkins plus
  visual confirmation; the deviation is stored in cache metadata and requires blinded detector
  validation before a paper-fidelity claim.
- All current 3D inference is disabled. A valid null must shift/block-resample complete spindle
  trains relative to SOs and repeat pairing, contact aggregation, and the cohort statistic. The
  N2-like versus N3-like comparison additionally needs matched contact sets and event-count control.
- Intracranial voltage polarity/reference is not calibrated to Naji's negative scalp downstate, and
  a sign flip rotates SO phase by π. Until polarity is anatomically/physiologically oriented or a
  validated sign-invariant sensitivity analysis is prespecified, 3B timing and 3D preferred phase
  are not source-comparable.
- No current-version real-data cohort has yet been rerun; synthetic tests validate failure modes
  and estimator behavior, not the biological result.
- A nonsignificant result means “not detected,” not “absent,” unless an equivalence analysis
  excludes a prespecified scientifically meaningful effect.

## Rebuild and verify

Raw HUP data/caches are not committed and require iEEG.org access.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r env/requirements.txt

.venv/bin/python analysis/cache_lc_series.py --force
.venv/bin/python analysis/lecci_faithful_3A.py --force
.venv/bin/python analysis/event_3B_cached.py --force
.venv/bin/python analysis/event_3D_by_stage.py --force

.venv/bin/python analysis/stage_ds003848.py --force
.venv/bin/python analysis/run_ds003848_replication.py --force

.venv/bin/python analysis/summarize_corrected_3AB.py
.venv/bin/python analysis/summarize_event_3D.py
```

`summarize_corrected_3AB.py` and `summarize_event_3D.py` print validated summaries. They refuse
legacy, non-production/mixed-configuration, byte-mismatched, manifest-free, failed, or unaccounted
outputs. For 3A/3B, unavailable endpoints are excluded and reported while other valid endpoints
from a partial record retain their own denominators; at least five estimable participants are
required per summarized endpoint by default. They do not overwrite historical text files.

Run the available checks:

```bash
.venv/bin/python -m pip check
.venv/bin/python -m compileall -q analysis
.venv/bin/python analysis/test_corrected_estimators.py
.venv/bin/python analysis/test_lecci_faithful.py
.venv/bin/python analysis/test_spectral_gapped.py
.venv/bin/python analysis/test_3B_null.py
.venv/bin/python analysis/test_run_integrity.py
.venv/bin/python analysis/test_coherence_calibration.py --require-real-cache
```

The last command deliberately fails publication/QC mode if no current real cache was tested.
