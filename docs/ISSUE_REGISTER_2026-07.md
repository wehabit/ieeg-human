# LC-proxy audit issue register — 2026-07

## Verdict

The legacy analysis was not technically defensible. The concerns below are real because they are
supported by at least one of:

1. an executable counterexample with known ground truth;
2. an exact mismatch with the cited primary method;
3. a reproducibility path that demonstrably accepts stale/partial data; or
4. a construct-validity gap that no code can bridge.

The working tree fixes the confirmed implementation defects marked **FIXED**. The separate
**OPEN** section contains scientific/validation limitations that code changes have not resolved.
No corrected cohort result has been generated: all committed 3A, 3B, and 3D JSON is legacy. The GitHub branch
itself remains unchanged until these local edits are reviewed, committed, and pushed.

Run:

```bash
.venv/bin/python analysis/audit_issue_evidence.py
.venv/bin/python analysis/test_corrected_estimators.py
.venv/bin/python analysis/test_lecci_faithful.py
```

The first script demonstrates why the legacy code fails; the tests verify the corrected helper
behavior. Neither substitutes for raw-data QC or a corrected cohort rerun.

## What SWA means

**SWA** is **slow-wave activity**: broadband EEG/iEEG power at approximately **0.5–4 Hz** in the
human Lecci analysis. It tends to increase with deeper NREM. SWA is not an individual slow
oscillation (SO), and neither SWA nor an SO is an LC measurement.

Commit a screening manifest with every candidate, access result, ECG/iEEG/anatomy QC, inclusion/exclusion reason, and reviewer/date. |
| B8 | High inference | **The 3D N2-like versus N3-like contrast has additional unresolved bias.** | All 3D inference is already disabled under B15. A future stage contrast must also use the same-contact intersection, control unequal event counts, and preserve serial dependence in a within-participant stage/block null; the iid algebraic magnitude correction is invalid. |
| B9 | High | **Naji’s headline behavioral endpoint is absent.** | Naji’s inferential finding related SO–HR timing to perceptual speed across visits. A physiological timing curve alone does not replicate that finding. Describe 3B as an adapted physiological comparison or collect the behavioral endpoint. |
| B10 | High | **Corrected real-data results do not exist yet.** | E6 finds 0/23 current 3A, 0/23 current 3B, and 0/25 current 3D files. Rebuild both cohorts, inspect run manifests/QC, and regenerate summaries before any biological conclusion. |
| B11 | High interpretation | **Nonsignificance cannot establish absence.** | A detection test with `p>.05` is not evidence that the effect is zero. Prespecify a smallest effect of interest based on a biologically meaningful Lecci-sized signal, report confidence intervals/power, and run an equivalence/non-inferiority analysis before using “absent.” |
| B12 | Moderate–high confounding | **Respiration/apnea, medication, tachycardia, seizures, arousals, and reference/polarity remain possible common drivers.** | Sigma, SOs, and HR are nonspecific. Add available respiration/movement/arousal/medication/seizure covariates, sensitivity exclusions, and polarity/reference checks. These do not create LC specificity but reduce obvious alternative explanations. |
| B13 | High inference | **3B lacks a validated event-locking null under nonstationary HR and clustered SOs.** | Same-stage/shared-channel shifts repair the older offset and pseudo-precision bugs but can move events away from the local trend that caused them to cluster. Prespecify and validate a local pre/post estimand plus a within-block/cycle-shift or block-resampling null that preserves slow trends, stage bouts, event density, and multichannel dependence. Until then all 3B magnitudes/timings are descriptive. |
| B14 | High method/raw QC | **Current ECG processing does not replicate Naji's detector and has not been validated on these records.** | Naji filtered ECG at 0.5–100 Hz, used Pan–Tompkins, and visually confirmed R peaks. The pinned code uses NeuroKit2 0.2.13 `method="neurokit"` cleaning/detection; its documented cleaner is a 0.5 Hz high-pass plus power-line filtering and its detector is NeuroKit's own, not Pan–Tompkins. The cache now records this deviation explicitly. Do not silently switch algorithms: compare candidate detectors against blinded manually adjudicated R peaks, report sensitivity/precision/timing error and downstream robustness, then prespecify one. |
| B15 | Critical inference | **The current 3D event-pairing operation itself induces a shared phase under independence.** | In E17, 25 participants × 3 contacts × 30 minutes of independent spindle/SO trains all pass the pooled QC gate, yet nearest-event selection inside ±2 s yields an invalid participant-rotation p < .001. Analytically, truncating event offsets to a finite SO-centered window is not phase-uniform. Keep every 3D p value disabled until complete spindle trains are shifted/block-resampled relative to SOs and detection, pairing, contact aggregation, and the cohort statistic are repeated inside the null. |
| B16 | Critical source transfer | **Intracranial polarity/reference is not calibrated to the source definitions.** | Naji defines a negative scalp downstate, but bipolar/depth polarity can reverse, so the same cortical event can be labeled an upstate. A voltage-sign flip also rotates 3D SO phase by π, allowing equal coupling on oppositely oriented contacts to cancel. Prespecify anatomical/reference orientation or validate a sign-invariant/sensitivity analysis before interpreting 3B timing, 3D preferred phase, or a negative result across contacts/participants. |

## C. Paper-method evidence

### Lecci et al. 2017

[Primary full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC5298853/):

- human SWA 0.5–4 Hz and sigma 10–15 Hz;
- artifact/movement-free visually scored NREM;
- four-cycle Morlet power every 0.1 s and mandatory symmetric 4 s smoothing;
- second Morlet analysis over 0.001–0.12 Hz, bouts ≥120 s, duration-weighted;
- three-Gaussian fit, fitted spectral SD, and peak-window mean;
- 120 s z-scored sigma/HR intervals, HR as source wave, averaged within then across participants;
- FSP visually identified from overlapping artifact-free NREM spectra;
- LC/brainstem mechanisms discussed as possibilities, not measured in humans.

### Naji et al. 2019

[Primary manuscript](https://escholarship.org/uc/item/5393b9zk):

- ECG 0.5–100 Hz, Pan–Tompkins R peaks with visual confirmation;
- RR resampled at 4 Hz with piecewise cubic interpolation;
- F3/F4 SOs at 0.15–4 Hz with Dang-Vu morphology criteria;
- one 10 s RR average per electrode;
- HR maximum/RR minimum time per electrode, then average electrode times;
- principal endpoint: visit-specific SO–HR timing related to perceptual speed, not an LC measure.

### Staresina et al. 2015 and Helfrich et al. 2018

[Staresina full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC4625581/) and
[Helfrich full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC5754239/):

- SO 0.16–1.25 Hz and fixed spindle 12–16 Hz;
- complete SO cycle/amplitude and spindle RMS/duration criteria;
- artifact-free NREM and manual/visual validation;
- Helfrich takes one maximal spindle amplitude and corresponding SO phase per SO epoch;
- neither paper validates LC activity.

### Osorio-Forero et al. 2021

[Final article](https://doi.org/10.1016/j.cub.2021.09.041) and
[primary preprint/methods](https://doi.org/10.1101/2021.03.08.434399):

- direct LC/terminal optogenetics, thalamic NE measurement, receptor blockade, and autonomic
  pharmacology establish a noradrenergic mechanism in mice;
- they do not validate this branch’s human iEEG/ECG measures as LC-specific.

## D. Publication acceptance gate

Do not restore biological result language until all of the following pass:

1. every expected participant is completed or has one prespecified, documented exclusion;
2. every cache/result has the current schema, cache-producer digest, complete configuration,
   source/code/runtime provenance, and successful terminal manifest;
3. no acquisition failures and ≥80% required-signal coverage;
4. expert/validated staging and anatomy/SOZ/bad-contact QC;
5. blinded missing-boundary/ECG/SO/spindle/artifact detector validation;
6. 3A reference-implementation benchmark;
7. no 3D p value until a pairing-aware null repeats full event pairing and contact aggregation;
   do not report N2-like/N3-like until its additional matched-contact/count-controlled test is
   validated;
8. synthetic tests plus real-cache coherence calibration;
9. corrected summaries generated from only current outputs, with explicit endpoint status and
   denominators;
10. confidence intervals and equivalence logic appropriate to any absence claim.

Until then, the accurate conclusion is:

> The repository now contains safer, tested estimators for LC-motivated downstream physiology, but
> it does not yet contain a validated corrected cohort result or proof of human LC tracking.
